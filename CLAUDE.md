## Claude Code workflow

- Follow AGENTS.md as the shared source of project instructions.
- Before implementing a task, inspect the relevant code, tests,
  configuration, and current Git state.
- For research or architecture tasks, investigate alternatives and
  present trade-offs before recommending a decision.
- Do not treat a hypothesis as an established research contribution.
- Do not silently choose a dataset, architecture, memory representation,
  evaluation metric, or research method when the decision is unresolved.
- For substantial changes, propose a plan and wait for approval before
  editing files.
- Keep changes focused and explain why each dependency is necessary.
- Never claim a test, experiment, or benchmark passed unless it actually ran.
- Ask before destructive operations, publishing, deploying, using paid
  services, or starting expensive compute jobs.
- Do not commit or push unless explicitly asked.
