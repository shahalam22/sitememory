
# Architecture Decision Records

Record significant technical decisions here.

Use a separate numbered document for each decision.
Keep the record concise, evidence-based, and easy to revisit.

Suggested naming:
- `0001-python-runtime.md`
- `0002-memory-representation.md`
- `0003-object-association.md`

## Decision lifecycle

- Proposed: alternatives are being investigated.
- Accepted: the decision has been made.
- Superseded: a later decision replaces it.

A decision should record its context, alternatives, trade-offs,
evidence, outcome, and conditions for reconsideration.
